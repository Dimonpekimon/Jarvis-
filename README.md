# Джарвис v3.3.1

Голосовой ассистент для Windows: локальное распознавание речи (Vosk),
нейронный синтез голоса, нейросеть Gemini (бесплатный API) и управление компьютером.

```
Вы: «Джарвис, какая погода в Москве»
Джарвис: «В городе Москва сейчас переменная облачность, 19 градусов...»
```

---

## Что изменилось в v3.3.1

Правки про запуск настольного окна — ассистент работал голосом, а окно
не появлялось.

- **Окно запускается без Node.js.** `npm` нужен только для `npm install` и
  `npm run build`; готовая сборка (`desktop/dist` + `electron.exe`) стартует
  сама. Раньше проверка `npm` стояла перед проверкой сборки, и сломанный Node
  навсегда «убивал» интерфейс. Поиск node/npm теперь идёт не только по `PATH`,
  но и по стандартным местам (nvm, fnm, scoop, Volta, `Program Files\nodejs`),
  плюс переопределение `JARVIS_NODE` / `JARVIS_NPM`.
- **Обход падения GPU-процесса Electron.** Сторонние DLL в песочнице GPU роняли
  окно за пару секунд (`GPU process isn't usable. Goodbye.`, код 2147483651);
  `--disable-gpu` не помогал. Теперь окно перезапускается с
  `--disable-gpu-sandbox`, а флаг запоминается в `data/overlay_flags.json`.
- **Повторный клик по ярлыку** не поднимает второй экземпляр (два голосовых
  цикла дрались бы за микрофон) — показывается окно уже работающего ассистента.
- Если окно не поднялось в фоновом режиме, ассистент **говорит об этом вслух**:
  консоли нет, и раньше поломка выглядела как «приложение не запускается».
- `--check` больше не путает **блокировку региона Gemini** (`User location is
  not supported`) с неверным ключом и подсказывает про VPN/прокси.

## Что изменилось в v3.3

**Веб-версии больше нет.** Браузерная страница (`web/`, `python webui.py`)
удалена — интерфейс теперь только настольный. `python main.py` сразу открывает
окно Electron, а Python остаётся ядром и отдаёт окну данные по HTTP/SSE на
локальном адресе.

- `webui.py` → `api.py` (класс `CoreAPI`): только API — состояние, поток
  событий, реплики, прерывание, сброс. Раздачи HTML и открытия браузера в коде
  больше нет.
- Настройки `WEB_UI_*` → `API_HOST` и `API_PORT`. Старые ключи из
  `jarvis_settings.json` читаются и переносятся автоматически, поэтому порт не
  сбросится.
- `--desktop` стал режимом по умолчанию; вместо него появился `--no-desktop`
  (консоль и голос без окна), `--ui-port` → `--api-port`.
- `run_overlay.bat` удалён: `run_jarvis.bat` и ярлык на рабочем столе запускают
  окно сами.

## Что изменилось в v3.2

**Настольное окно.** Появился отдельный интерфейс на Electron + TypeScript +
React (`desktop/`) — прозрачная карточка поверх рабочего стола со
столбиками-визуализатором в стиле Winamp, историей диалога и полем ввода.
Окно не мешает работать: клики проходят сквозь него везде, кроме полей и
кнопок. Два режима — обычный и полупрозрачный.

Запускается одной командой (`python main.py --desktop` — флаг v3.2; в v3.3 это режим по умолчанию): Python остаётся мозгом
и голосом, Electron — только окном. Сборка выполняется автоматически при первом
запуске и при изменении исходников. Python-часть при этом не переписывалась —
окно общается с ядром по уже существующему HTTP/SSE API.

## Что изменилось в v3.1

**Распознавание речи** — `faster-whisper` заменён на **Vosk**. Небольшая русская
модель (~45 МБ) работает на CPU за доли секунды, полностью офлайн и не требует
ни GPU, ни скачивания гигабайтов. Модель скачивается автоматически при первом
запуске в `data/models`.

**Голос** — синтез переведён на локальный **Piper**. Нейронный голос
`ru_RU-dmitri-medium` работает офлайн, не зависит от серверов Microsoft и не
требует интернета. Модель (~63 МБ) скачивается автоматически. `edge-tts` и SAPI
остались резервом.

**Мозг** — локальная **Ollama** заменена на **Gemini API** (бесплатный тариф).
Ничего устанавливать не нужно: ключ уже лежит в `jarvis_settings.json`
(`GEMINI_API_KEY`), модель по умолчанию — `gemini-3.5-flash`. Она же умеет
смотреть скриншоты, поэтому анализ экрана работает без отдельной vision-модели.
Если основная модель занята, запрос автоматически уходит на запасную
(`GEMINI_FALLBACK_MODELS`).

## Что было в v3.0

**Распознавание речи** — `speech_recognition` + Google заменены на локальный
**faster-whisper**. Работает офлайн, ничего не отправляется в Google, качество
на русском заметно выше.

**Синтез речи** — `pyttsx3` (роботизированный SAPI) заменён на **edge-tts**
(нейронные голоса Microsoft). Если интернета нет — автоматически включается
локальный **piper**, а если и его нет — старый pyttsx3 как последний резерв.

**Мозг** — локальная **Ollama** с моделью **Mistral 7B**. Никаких платных API,
всё считается на вашем компьютере.

**Исправленные баги** (главные):

| Баг | Что было | Что стало |
|---|---|---|
| Калькулятор не считал | Слова «плюс/минус» удалялись из фразы **до** замены на символы, поэтому `2 плюс 2` превращалось в `2 2` | Операторы заменяются первыми; добавлен разбор чисел прописью |
| «выключи компьютер» выключало звук | Команда громкости перехватывала фразу, потому что в её синонимах было слово «выключи» | Синонимы сопоставляются по длине: «выключи компьютер» (17 символов) побеждает «выключи» (7) |
| «напомни через час» показывало время | Синоним «час» срабатывал как подстрока в любом слове | Сопоставление идёт по границам слов: «час» больше не ловится в «сейчас» и «часто» |
| Таймер на 10 секунд шёл 60 секунд | Длительность считалась в минутах с округлением вверх | Время разбирается в секундах, поддержаны «полчаса» и «полтора часа» |
| Опасная очистка корзины | `rd /s /q C:\$Recycle.Bin` — удалял служебную папку Windows и требовал прав администратора | Штатная команда `Clear-RecycleBin` |
| Калькулятор через `eval` | Любое выражение исполнялось интерпретатором | Безопасный разбор через AST: только числа и арифметика |
| Напоминания терялись при перезапуске | Хранились только в памяти | Сохраняются в `data/reminders.json` и восстанавливаются |
| Джарвис падал без интернета | При недоступности Ollama не было понятного ответа | Понятное объяснение + автоматический переход на веб-поиск |
| Запросы к Ollama падали с 502 | Системный `HTTP_PROXY` перехватывал обращения к `127.0.0.1` | Локальное соединение идёт напрямую, прокси обходится |
| Модель грузилась при каждом запросе | `pyttsx3.init()` вызывался при импорте модуля | Ленивая инициализация + кэш синтезированных фраз |

**Оптимизации**: единый поток аудио вместо переоткрытия микрофона на каждый
блок, кэш озвучки, прогрев модели распознавания при старте, потокобезопасный логгер,
ленивая загрузка всех тяжёлых библиотек.

**Новые возможности**: планировщик с сохранением напоминаний, утренний брифинг,
**составные команды**, чтение текста с экрана через встроенный OCR Windows,
анализ экрана нейросетью, Telegram-бот, уведомления Windows, список окон,
PowerShell, работа с буфером обмена, отмена выключения, больше приложений и команд.

**Добавлено позже**:

- **Быстрый голосовой цикл.** Раньше каждая команда требовала двух записей с
  распознаванием (обращение, потом команда) — это давало лишние ~1,6 с. Теперь
  «Джарвис, который час» обрабатывается одной фразой. Подробности — в разделе
  «Голосовое общение».
- **Отклик на обращение** — «Да, сэр, к вашим услугам». Звучит только тогда,
  когда команда не прозвучала в той же фразе.
- **Одна команда на одно «Джарвис».** После выполнения команды нужно снова
  сказать слово-активатор: иначе ассистент реагировал бы на любой разговор.
- **Приветствие по времени суток** при запуске.
- **«Выключайся» гасит всё** — и голосовой цикл, и интерфейс.
- **Скриншоты в «Документы → Скриншоты Джарвиса»**.
- **«Джарвис.exe» в диспетчере задач** вместо `pythonw.exe`.
- **Список команд в «Документы → Джарвис — команды.txt»**.

## Аудит и доработка (ревизия 2)

Полный разбор кода на ошибки, недочёты и узкие места. Ниже — что найдено и что
сделано.

### Исправленные ошибки

| Что | Подробности |
|---|---|
| **Команды без обработчика** | `repeat` («повтори ответ») и `cancel_last_task` («отмени последнюю задачу») были объявлены в реестре `INTENTS`, но методов-обработчиков не существовало — фраза молча уходила в LLM и отвечала не то. Написаны `_h_repeat` и `_h_cancel_last_task`. |
| **Список команд отстал от кода** | В `Документы/Джарвис — команды.txt` не было этих двух команд, из-за чего автосверка падала на двух проверках. Файл пересобран. |
| **README о Telegram противоречил коду** | В документе было «пустой список = разрешено всем», хотя бот требует непустой список ID и иначе не стартует. Текст приведён в соответствие с кодом. |
| **README: неверные значения по умолчанию** | `SILENCE_SEC` был указан как `1.0`, фактически `0.5`. `TTS_ENGINE` в `config.py` стоял `sapi`, хотя документация и файл настроек говорят `auto` — приведено к единому виду. |
| **Неиспользуемые импорты** | В `jarvis_core.py` убраны `shutil` и `extract_duration` — они не использовались. |

### Оптимизации

- **Кэш регулярных выражений при сопоставлении команд.** `contains_word` заново
  компилировал regexp на каждый вызов, а одна фраза прогоняется через все ~250
  синонимов (и до четырёх раз за команду). Теперь шаблон компилируется один раз
  и берётся из `lru_cache`.
- **Кэш распознанных намерений.** `match_intent` запоминает результат для фразы
  (до 256 записей), поэтому при разборе составной команды одни и те же части
  сопоставляются один раз, а не дважды.

### Новые команды

- **О компьютере:** «сведения о системе», «сколько места на диске», «сколько
  оперативной памяти», «заряд батареи», «сколько работает компьютер», «какой у
  меня ip».
- **Питание и экран:** «выключи монитор», «спящий режим».
- **Утилиты:** «подбрось монетку», «брось кубик», «случайное число от 1 до 100»,
  «сгенерируй пароль», «открой загрузки» (а также рабочий стол, документы,
  музыку, картинки).

Всё работает через `ctypes` и стандартную библиотеку — новых зависимостей
проект не потянул.

### Новые проверки в селфтесте

- **У каждой команды есть обработчик.** Сверяет реестр `INTENTS` с методами
  класса: именно этот тест поймал бы «повтори ответ». Плюс проверки на пустой
  список синонимов и уникальность имён команд.
- Маршрутизация всех новых команд и работа утилит (монетка, кубик, пароль,
  память, аптайм, IP, место на диске).

Итого автопроверок: **273** (было 211).

## Установка

### 1. Зависимости Python

```bash
pip install -r requirements.txt
```

### 2. Gemini API (мозг ассистента)

Ключ уже прописан в `jarvis_settings.json` — ничего дополнительно ставить не
нужно. Если файла настроек нет или ключ нужно заменить, получите бесплатный
ключ в [Google AI Studio](https://aistudio.google.com/apikey) и укажите его:

```json
{
  "GEMINI_API_KEY": "ваш-ключ"
}
```

Ключ можно задать и переменной окружения `GEMINI_API_KEY` — настройки имеют
приоритет.

Модель по умолчанию — `gemini-3.5-flash`. Она быстро отвечает по-русски и
понимает картинки, поэтому отдельная vision-модель не требуется. Другая модель:

```json
{
  "GEMINI_MODEL": "gemini-3.5-flash-lite",
  "GEMINI_FALLBACK_MODELS": ["gemini-3.5-flash-lite"]
}
```

**Джарвис работает и без Gemini.** Все команды (время, погода, калькулятор,
громкость, напоминания, скриншоты, OCR, поиск) обрабатываются собственными
модулями. Нейросеть нужна только для свободных вопросов вроде «объясни, почему
небо голубое»: без неё ассистент честно скажет об этом.

Бесплатный тариф ограничен числом запросов в минуту. При исчерпании лимита
ассистент попросит подождать минуту; обычные команды при этом работают.

Проверить ключ и модель: `python main.py --check`.

### 3. Проверка

```bash
python main.py --check
```

Покажет, что установлено, что доступно и чего не хватает.

## Запуск

```bash
python main.py              # настольное окно + голос и текст
python main.py --text       # только текстовый ввод
python main.py --voice      # только голос
python main.py --no-tts     # без озвучки
python main.py --no-wake    # голос без слова-активатора «Джарвис»
python main.py --check      # диагностика окружения
python main.py --list-voices  # доступные русские голоса
python main.py --no-desktop # без окна: консоль, голос, API ядра
python main.py --api-port 9000  # другой порт API ядра
python main.py --background # фоновый запуск без консоли (режим ярлыка)
python main.py --rebuild-desktop  # пересобрать окно и запустить
```

Или просто двойным кликом по **`run_jarvis.bat`**.

### Настольное окно

Запуск без флагов поднимает ассистента и открывает отдельное окно Electron
поверх рабочего стола: полупрозрачная карточка со столбиками-визуализатором,
история диалога и поле ввода. Браузерная версия удалена — других интерфейсов
нет.

```
Джарвис (Python: Vosk + Piper + Gemini)   ← мозг, микрофон, озвучка
        │ HTTP/SSE на 127.0.0.1:8765
        ▼
Оверлей (Electron: Canvas + AnalyserNode) ← только окно
```

Что происходит при запуске:

1. ищется Node.js: сначала в `PATH`, затем в стандартных местах установки
   (`Program Files\nodejs`, `%LOCALAPPDATA%\Programs\nodejs`, nvm, fnm, scoop,
   Volta) — путь можно задать и вручную: `JARVIS_NODE` / `JARVIS_NPM`;
2. если зависимостей нет — один раз выполняется `npm install` (пара минут);
3. если сборка отсутствует **или исходники в `desktop/src` новее её** —
   выполняется `npm run build`;
4. запускается `electron.exe` с `JARVIS_NO_SIDECAR=1` — второй экземпляр ядра
   не создаётся, микрофон остаётся за Python;
5. при выходе ассистента окно закрывается вместе с ним.

Node.js нужен **только для установки зависимостей и пересборки окна**. Если
сборка (`desktop/dist`) и `electron.exe` уже на месте, окно запускается и без
Node — сломанный Node больше не «убивает» интерфейс.

Если GPU-процесс Electron падает на старте (сторонние DLL от антивируса или
оверлея, драйвер), окно закрывается за пару секунд. Ассистент это замечает,
перезапускает его с `--disable-gpu-sandbox` и запоминает флаг в
`data/overlay_flags.json` — дальше окно поднимается сразу. Полностью выключить
аппаратный рендер: `JARVIS_DISABLE_GPU=1`.

Если окно так и не появилось, ассистент продолжает работу голосом и говорит об
этом вслух; подробности — в `data/jarvis.log`, диагностика —
`python main.py --check`.

Управление окном: `Ctrl+Alt+J` — обычный/полупрозрачный режим, `Ctrl+Alt+U` —
компактный вид/диалог, `Ctrl+Alt+Space` — прервать речь, `Esc` — прервать или
свернуть. Подробности и устройство — в `desktop/README.md`.

### Ярлык на рабочем столе (фоновый запуск)

```bash
python make_shortcut.py
```

Создаёт на рабочем столе ярлык **«Джарвис»**, который запускает
`Джарвис.exe main.py --background`:

| | |
|---|---|
| Окно консоли | нет — ассистент живёт в фоне |
| Имя процесса | **«Джарвис.exe»** — так он виден в диспетчере задач |
| Текстовый ввод | не спрашивается (набирать его негде) |
| Управление | голосом («Джарвис, ...») и через настольное окно |
| Лог | `data/jarvis.log` — консоли нет, поэтому пишем в файл |
| Интерфейс | открывается настольное окно |

`Джарвис.exe` — это копия `pythonw.exe` рядом с проектом. Диспетчер задач
берёт название процесса из имени файла, поэтому переименованная копия видна
как «Джарвис.exe», а не «pythonw.exe». Python работает нормально: свою
библиотеку интерпретатор находит по реестру, а не по имени файла.

**Повторный клик по ярлыку** не запускает второй ассистент (два голосовых
цикла подрались бы за микрофон): программа видит, что ядро на порту 8765 уже
отвечает, и просто показывает окно работающего экземпляра. Так же возвращается
окно, если его закрыли крестиком, — сам ассистент при этом продолжает слушать.

Полностью выключить всё — голосом: «Джарвис, выключайся» (гасит голос, API и
окно). Пункт «Выход» в меню значка в трее закрывает только окно.

Если копию делать не нужно — `python make_shortcut.py --no-exe-copy`.

Удалить ярлык: `python make_shortcut.py --remove` (заодно убирает копию).

**При первом запуске** скачиваются две модели: Vosk (~45 МБ) в `data/models` для
распознавания и голос Piper (~63 МБ) в `data/voices` для озвучки. Это разовая
операция; дальше и распознавание, и голос работают полностью офлайн.

## Голос

Основной движок — **Piper**: локальная нейросеть, работает офлайн и ничего не
отправляет в облако. Голос по умолчанию — `ru_RU-dmitri-medium` (мужской,
похож на Джарвиса). Модель (~63 МБ) скачивается автоматически при первом запуске
в `data/voices`.

Посмотреть доступные русские голоса:

```bash
python main.py --list-voices
```

Скачать и выбрать другой:

```bash
python download_voices.py irina
```

```json
{
  "PIPER_MODEL": "data/voices/ru_RU-irina-medium.onnx",
  "TTS_ENGINE": "piper"
}
```

Скорость и громкость: `PIPER_SPEED` (1.0 — обычная, 1.2 — быстрее, 0.8 —
медленнее) и `PIPER_VOLUME` (0..1).

### Резервные голоса

Если Piper почему-то не завёлся, ассистент по очереди пробует **edge-tts**
(нейронные голоса Microsoft, нужен интернет), затем **SAPI** Windows. Голос
edge-tts задаётся `TTS_VOICE` — по умолчанию `ru-RU-DmitryNeural`. Принудительно
выбрать движок: `"TTS_ENGINE": "edge"` или `"sapi"`.

```bash
python main.py --list-voices   # покажет и Piper, и edge-tts
```

## Голосовое общение

**Одна команда — одно «Джарвис».** После выполнения команды ассистент снова ждёт
обращение и продолжение разговора не слушает: иначе он реагировал бы на любой
разговор в комнате. Правило живёт в `Jarvis._next_utterance()`.

Есть два способа сказать команду:

```
Вы: «Джарвис, который час»          ← быстро: одно распознавание, ~3 с
Джарвис: «Сейчас 15:48, сэр.»

Вы: «Джарвис»                        ← ассистент отвечает и слушает дальше
Джарвис: «Да, сэр, к вашим услугам.»
Вы: «который час»
Джарвис: «Сейчас 15:48, сэр.»
```

**Совет: говорите команду в один вдох с обращением** — тогда она распознаётся
вместе со словом-активатором, и второе распознавание не нужно. Отклик «Да, сэр»
звучит только тогда, когда команды в той же фразе не было.

Фразы отклика лежат в `responses.py` → ключ `wake_ack`, включается настройкой
`WAKE_ACK_ENABLED`.

### Почему ответ идёт несколько секунд

| Этап | Время | Где настройка |
|---|---|---|
| Запись фразы (речь + пауза) | речь + 0,5 с | `SILENCE_SEC` |
| Распознавание Vosk | 0,2–1,0 с | `VOSK_MODEL_NAME` |
| Ответ команды | ~0,05 с | — |
| Ответ на свободный вопрос | 1–3 с | `GEMINI_MODEL` |
| Синтез Piper | 1–2 с (кэш — мгновенно) | `PIPER_SPEED` |

Vosk распознаёт фразу целиком за один проход и на порядок быстрее прежнего
Whisper: небольшая модель работает на CPU без GPU. Если нужна максимальная
точность, можно скачать большую модель Vosk и указать её в
`VOSK_MODEL_NAME` / `VOSK_MODEL_PATH` — но она потребует заметно больше
памяти и времени на загрузку.

## Telegram-бот

Управление ассистентом с телефона. Получите токен у [@BotFather](https://t.me/BotFather)
и укажите в `jarvis_settings.json`:

```json
{
  "TELEGRAM_ENABLED": true,
  "TELEGRAM_TOKEN": "123456:ABC-ваш-токен",
  "TELEGRAM_ALLOWED_USERS": [ваш_telegram_id]
}
```

Пустой список `TELEGRAM_ALLOWED_USERS` = доступ закрыт: бот просто не запустится.
Список **обязателен** — это защита по умолчанию, чтобы ботом не мог управлять
кто угодно, узнавший токен. Свой ID можно узнать у
[@userinfobot](https://t.me/userinfobot).

Команды бота: `/status`, `/reset`, `/help`.

## Команды

| Категория | Примеры фраз |
|---|---|
| **Система** | «громче», «тише», «громкость на 40», «выключи звук», «ярче», «темнее», «яркость на 70» |
| **Питание** | «заблокируй экран», «выключи компьютер», «завершение работы», «перезагрузи компьютер», «отмена выключения» |
| **Программы** | «открой браузер», «открой ютуб», «запусти стим», «запусти роблокс», «запусти роблокс студио», «открой вскод», «открой терминал», «блокнот», «диспетчер задач» |
| **Окна** | «переключи окно», «сверни», «разверни», «закрой окно», «какие окна открыты» |
| **Время** | «который час», «какое сегодня число», «погода в Москве», «брифинг» |
| **Задачи** | «напомни через 10 минут позвонить маме», «таймер на 5 минут», «мои напоминания», «отмени все напоминания», «отмени последнюю задачу» |
| **Умное** | «посчитай 2 плюс 2», «найди в интернете курс доллара», «что на экране», «прочитай что на экране» |
| **Разное** | «сделай скриншот», «запиши заметку купить хлеб», «прочитай заметки», «что в буфере обмена», «расскажи шутку», «повтори ответ», «статус систем» |
| **Компьютер** | «сведения о системе», «сколько места на диске», «сколько оперативной памяти», «заряд батареи», «сколько работает компьютер», «какой у меня ip», «выключи монитор», «спящий режим» |
| **Утилиты** | «подбрось монетку», «брось кубик», «случайное число от 1 до 100», «сгенерируй пароль», «открой загрузки», «открой рабочий стол» |
| **Выключение ассистента** | «выключайся», «отключись», «отключи» — гасит и голосовой цикл, и настольное окно |

Всё, что не совпало ни с одной командой, уходит в нейросеть — можно просто
поговорить: «объясни, что такое рекурсия».

Полный список — **`Документы → Джарвис — команды.txt`**: по одной фразе на
команду и пояснение, что она делает. Файл создаётся скриптом
`python make_commands_list.py`, который сверяется с реестром команд в коде.

### Скриншоты

Команда «сделай скриншот» снимает **все** экраны и кладёт файл в
**`Документы → Скриншоты Джарвиса`**, имя вида
`Jarvis_Screenshot_20260923_165239.png`. Папка создаётся при запуске
ассистента и при первом снимке.

### Приветствие при запуске

Ассистент здоровается по времени суток: до 12 — «Доброе утро, сэр», до 18 —
«Добрый день», до 23 — «Добрый вечер», ночью — «Доброй ночи».

### Составные команды

Одной фразой можно отдать до трёх команд — они выполнятся по порядку:

> «Сделай громче **и** напомни через 5 минут позвонить маме»

Фраза делится только тогда, когда **каждая** часть распознаётся как известная
команда. Поэтому «включи музыку и танцуй» или «объясни разницу между и или»
не разорвутся — они целиком уйдут в нейросеть. Работают разделители:
«и», «и потом», «а потом», «затем», «после этого».

## Настройки

Файл **`jarvis_settings.json`** создаётся автоматически при первом запуске.
Если файла нет, а хочется начать с готового шаблона — скопируйте
**`jarvis_settings.example.json`**.

> **`jarvis_settings.json` не попадает в репозиторий** (он в `.gitignore`):
> в нём ключ Gemini, токен Telegram-бота и личные пути. По той же причине исключены
> папка `data/` (модели Vosk, заметки, напоминания, логи) и файлы моделей `*.onnx`.
> Клонировав репозиторий, ничего лишнего вы не унаследуете.

Ключевые параметры:

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `VOSK_MODEL_NAME` | `vosk-model-small-ru-0.22` | Папка русской модели Vosk в `data/models` |
| `VOSK_AUTO_DOWNLOAD` | `true` | Скачивать модель автоматически, если её нет |
| `TTS_VOICE` | `ru-RU-DmitryNeural` | Голос edge-tts (резервный движок) |
| `TTS_RATE` | `+10%` | Скорость речи edge-tts |
| `TTS_ENGINE` | `piper` | `piper`, `edge`, `sapi`, `auto` |
| `PIPER_MODEL` | `ru_RU-dmitri-medium.onnx` | Файл голоса Piper в `data/voices` |
| `PIPER_SPEED` | `1.0` | Скорость Piper (1.2 — быстрее) |
| `PIPER_VOLUME` | `1.0` | Громкость Piper (0..1) |
| `GEMINI_API_KEY` | ключ из настроек | Бесплатный ключ Gemini |
| `GEMINI_MODEL` | `gemini-3.5-flash` | Основная модель для диалога |
| `GEMINI_VISION_MODEL` | `gemini-3.5-flash` | Модель для анализа картинок |
| `WAKE_WORDS` | `["джарвис", ...]` | Слова-активаторы |
| `WAKE_WORD_REQUIRED` | `true` | Требовать слово-активатор в голосовом режиме |
| `MAX_COMMAND_SEC` | `15.0` | Максимальная длина одной команды |
| `SILENCE_SEC` | `0.5` | Сколько тишины считать концом фразы |
| `WEATHER_DEFAULT_CITY` | `Москва` | Город по умолчанию |
| `API_HOST` | `127.0.0.1` | Адрес API ядра (только петлевой) |
| `API_PORT` | `8765` | Порт API (занят — берётся следующий) |

### Если Vosk путает слова

Модель `vosk-model-small-ru-0.22` — компромисс между скоростью и точностью.
Если качество не устраивает, скачайте более крупную русскую модель с
[alphacephei.com/vosk/models](https://alphacephei.com/vosk/models), распакуйте
её в `data/models` и укажите папку:

```json
{
  "VOSK_MODEL_NAME": "vosk-model-ru-0.42",
  "VOSK_MODEL_PATH": "data/models/vosk-model-ru-0.42"
}
```

Большая модель точнее, но требует больше памяти и грузится дольше. Короткие
команды («громче», «тише») она обычно понимает лучше.

Если слова путаются только в шуме — проверьте `VAD_RMS_THRESHOLD` и
перекалибруйте микрофон (калибровка идёт при каждом запуске).

### Анализ экрана

**Чтение текста с экрана работает сразу** — используется встроенный OCR-движок
Windows (`Windows.Media.Ocr`), ничего скачивать не нужно. Русский поддерживается,
если в системе установлен русский языковой пакет. Скажите: «прочитай, что на экране».

Проверить доступные языки OCR:

```bash
python -c "from winrt.windows.media.ocr import OcrEngine; print([l.language_tag for l in OcrEngine.available_recognizer_languages])"
```

Язык задаётся настройкой `OCR_LANGUAGE` (по умолчанию `ru`).

Чтобы Джарвис **описывал картинку целиком**, а не только читал текст, нужна
мультимодальная модель — она уже настроена:

```json
{ "GEMINI_VISION_MODEL": "gemini-3.5-flash" }
```

Тогда работают команды «что на экране», «проанализируй экран», «что я делаю».
Скриншот отправляется в Gemini; если он большой, он автоматически сжимается.

## Решение проблем

**«Ключ Gemini неверный» или «Нет связи с Gemini»** — проверьте `GEMINI_API_KEY`
в `jarvis_settings.json`, интернет и настройки прокси. Диагностика:
`python main.py --check`. Джарвис при этом продолжает работать: обычные команды
выполняются, но свободные вопросы останутся без ответа.

**«Бесплатный лимит Gemini исчерпан»** — подождите минуту. На бесплатном тарифе
действует ограничение на число запросов в минуту. Можно переключиться на
`gemini-3.5-flash-lite` — у неё отдельная квота.

**Микрофон не слышит** — проверьте, что приложение имеет доступ к микрофону
(Параметры → Конфиденциальность → Микрофон). Список устройств:
`python -c "import sounddevice; print(sounddevice.query_devices())"`

**Модель Vosk не скачалась** — скачайте архив
`https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip` вручную,
распакуйте в `data/models` и запустите снова. Проверить, что модель на месте:
`python -c "from speech import model_ready; print(model_ready())"`.

**Vosk медленно стартует** — загрузка модели занимает около секунды при запуске
и не повторяется. Если распознавание каждой фразы идёт дольше 2 секунд,
проверьте, что папка `data/models` не на сетевом диске.

**Голос не звучит** — основной движок Piper работает офлайн, поэтому интернет
ему не нужен. Проверьте, что модель на месте:
`python -c "from tts import piper_model_ready; print(piper_model_ready())"`.
Если модели нет — она скачается при первом запуске (или `python download_voices.py`).
В крайнем случае переключитесь на резерв: `"TTS_ENGINE": "sapi"`. Кэш озвучки
можно очистить, удалив `data/tts_cache`.

**Джарвис срабатывает сам** — увеличьте `VAD_RMS_THRESHOLD` (например, до
`0.02`) или перекалибруйте микрофон перезапуском.
