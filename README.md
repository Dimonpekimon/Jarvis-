🤖 Джарвис — голосовой ассистент для Windows

Голосовой ассистент на Python с распознаванием речи, локальной LLM (Ollama), управлением системой, поиском в интернете и напоминаниями.
🚀 Возможности:

🎙️ Wake Word	Слушает фоном, активируется по слову «Джарвис» / «Jarvis»

🧠 Ollama LLM	Отвечает на любые вопросы через локальную нейросеть (llama3.2 и др.)

🔍 Поиск в интернете	DuckDuckGo + Wikipedia fallback

🌤️ Погода	Open-Meteo API, без ключей

🎛️ Управление системой	Громкость, яркость, блокировка экрана, выключение/перезагрузка

⏰ Напоминания	Планировщик на threading.Timer — «напомни через 5 минут»

🧩 Fuzzy Matching	Понимает «сколько времени», «который час», «часы» как одно намерение

🧠 Контекст	Помнит 2–3 последних обмена репликами

📦 Приложения	Открывает VS Code, PyCharm, Steam, браузер, терминал

📦 Установка
1. Клонирование
git clone https://github.com/Dimonpekimon/jarvis-assistant.git
cd jarvis-assistant
2. Виртуальное окружение (рекомендуется)
python -m venv venv
venv\Scripts\activate
3. Базовые зависимости
pip install speechrecognition pyttsx3 sounddevice numpy requests wikipedia
4. Опциональные зависимости
# Управление громкостью
pip install pycaw comtypes

# Управление яркостью экрана
pip install screen-brightness-control

# Поиск в интернете (DuckDuckGo)

pip install duckduckgo-search

5. Ollama (локальная LLM)
 Скачай с ollama.com, установи и запусти модель:

 ollama run llama3.2

Модель можно поменять в коде: переменная OLLAMA_MODEL.

🎤 Настройка микрофона

Панель управления → Звук → Запись

Выбери активный микрофон → Свойства → Уровни

Установи 100% громкости и +10…+30 дБ усиления (если доступно)

Убедись, что микрофон по умолчанию — тот, который ты используешь

▶️ Запуск

python jarvis.py

Джарвис скажет: «Системы Джарвиса успешно запущены» и начнёт слушать wake word.

⚙️ Настройка:

Открой jarvis.py и поменяй:

Python

OLLAMA_MODEL = "llama3.2"      # своя модель из ollama list

OLLAMA_URL = "http://localhost:11434/api/generate"

SAMPLE_RATE = 16000

WAKE_DURATION = 4              # секунды на wake word

COMMAND_DURATION = 6           # секунды на команду

🛡️ Безопасность:

subprocess.Popen без shell=True — нет инъекций

Все пути приложений валидируются через os.path.exists

Ollama работает локально — данные не уходят в облако

🐛 Типичные проблемы:

"Не слышу" / тихий звук	Проверь уровень микрофона в Windows, усиль в +20 дБ

"Микрофон недоступен"	Закрой другие программы, использующие микрофон

Ollama не отвечает	Убедись, что ollama serve запущен

Не открывается PyCharm	Проверь путь в open_pycharm() под свой установщик
